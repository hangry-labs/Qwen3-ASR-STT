# Qwen3-ASR-STT examples

[Open the multilingual listening gallery](https://hangry-labs.github.io/Qwen3-ASR-STT/examples/).

## Recordings and reference transcripts

Choose one of 30 transcription languages to hear its representative recording
and read the reference text. The All filter shows every sample. Language filters
also translate the gallery; Arabic and Persian use right-to-left content while
the shared website navigation keeps its own language and direction.

These recordings are existing repository test fixtures generated by Hangry Labs
using external text-to-speech systems. They are input audio and reference text,
not live ASR results or a claim that the underlying voices or systems are ours.
The gallery preserves the same samples used by the repository validation corpus.

The catalog selects the first `random*` case for each supported language from
`testbench/manifest.json`. It contains the source file paths and reference text;
recordings remain under `testbench/assets/`. `catalog.js`, `translations.js` and
`page.js` supply the sample index, 30 gallery translations and existing player.

## Playback and languages

Use the play button, seek along the progress bar or adjust the shared volume.
Starting another sample pauses the previous one. Direct links accept `?lang=de`
and the other gallery locale codes; `?filter=all` displays every recording.

The shared website selector serves six translated READMEs. The gallery has its
own broader language catalog; Norwegian keeps English gallery content and shows
a fallback notice. The local Studio supports English, Polish, Japanese, Chinese,
Spanish and German independently of these public website translations.

## Local preview

Run `task pages` to build and preview the complete project website. Use
`task pages-build` to build without a server, or `task pages-test` for staging
and routing checks. These tasks do not load an ASR model or use a GPU.

`index.md` integrates the content from `index.html` into the shared shell.
The standalone `index.html` also opens directly from a downloaded checkout,
using the same local assets, player, recordings and translations. Keep the
`assets/`, `examples/` and `testbench/assets/` directories together. Alternatively:

```powershell
python -m http.server 9000
```

Open <http://localhost:9000/examples/index.html>.
